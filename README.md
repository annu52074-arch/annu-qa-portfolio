# Annu Srivastava — QA Automation Portfolio

A responsive, dark navy and blue portfolio website designed for GitHub Pages.

## Before publishing
1. Add your own profile picture at `assets/profile-photo.jpg` (square or portrait image recommended).
2. Review every project description and keep only work you have actually completed.
3. Add real GitHub repository/demo links if you have them. The project links currently take visitors to the contact section.
4. Verify your email address and education details before publishing.

## Publish with GitHub Pages
1. Sign in to GitHub and create a new **public** repository, for example `annu-qa-portfolio`.
2. Upload `index.html`, `style.css`, `script.js`, the `assets` folder, and this README to the repository root.
3. Open **Settings → Pages**.
4. Under **Build and deployment**, select **Deploy from a branch**.
5. Choose branch **main** and folder **/(root)**, then click **Save**.
6. Wait for GitHub Pages to publish. The URL usually looks like `https://YOUR-USERNAME.github.io/annu-qa-portfolio/`.

## Local preview
Open `index.html` in a browser. For best results, use a simple local server or VS Code Live Server.

## Files
- `index.html` — page structure and content
- `style.css` — responsive styling
- `script.js` — mobile navigation, current year, copy-email button
- `assets/profile-photo.jpg` — add your own photo here

No work experience, certification names, defect counts, or test results are fabricated. Update the content to match your actual work before sharing with recruiters.
